# 그림자 복도 공략 노트

그림자 복도(Shadow Corridor)의 배회자 이동 속도, 감지 거리, 추격 규칙, 맵 기믹을 정리한 비공식 팬 위키입니다.

**사이트: https://mugamta.github.io/ShadowCorridorHelper/**

## 페이지

| 페이지             | 내용                                                                         |
| ------------------ | ---------------------------------------------------------------------------- |
| 게임 시스템        | 적이 플레이어를 알아채는 시야·불빛·소리, 폭죽, 경계와 추격 해제 규칙         |
| 적                 | 배회자와 그 밖의 적. 적마다 속도, 위에서 본 감지 범위 그림, 특징             |
| 플레이어           | 걷기·달리기·앉아 걷기 속도, 적과 속도 비교, 스태미나                         |
| 아이템             | 낡은 카메라·손전등·폭죽·수정 구슬, 황금 열쇠와 문, 패시브, 아이템 줍기       |
| 맵                 | 증오를 흩뿌리는 그림자 등장 조건, 함정방, 무너지는 곳, 성역의 물, 레버와 문 |
| 정해진 아이템 자리 | 스테이지마다 매 판 같은 자리에 있는 아이템, 확정 선반·서랍                  |

## 읽는 법

- 거리와 속도는 게임 단위입니다. 100 = 1m, 속도는 초당 거리(130 = 초당 1.3m)입니다.
- 항목마다 출처를 표시합니다.
  - 표시 없음: 게임에서 확인한 내용
  - **미확인**: 아직 플레이로 확인하지 못한 내용
  - **추정**: 정황으로 짐작한 내용
- 난이도는 초보자·도전자·파괴자로 적습니다.

틀린 내용이나 새로 확인한 내용이 있으면 이슈로 알려 주세요.

## 개발

Nuxt 4 + Vue 3 정적 사이트입니다.

```bash
npm install
npm run dev        # 개발 서버
npm run generate   # 정적 빌드 → .output/public
npm run typecheck
npm run format
```

`main`에 push하면 GitHub Actions가 GitHub Pages로 배포합니다.

## 알림

팬이 만든 비공식 사이트이며 게임 제작사와 관계없습니다.
