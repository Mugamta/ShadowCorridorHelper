# 그림자 복도 공략 노트 (ShadowCorridorHelper)

그림자 복도(Shadow Corridor)의 배회자 이동 속도, 감지 거리, 추격 규칙, 맵 기믹을 정리한 비공식 팬 사이트입니다.
게임 파일 분석과 실제 플레이 기록을 바탕으로 하며, 항목마다 출처(확인 / 파일 / 추정)를 표시합니다.

## 개발

```bash
npm install
npm run dev
```

정적 빌드: `npm run generate` → `.output/public`

`main`에 push하면 GitHub Actions가 GitHub Pages로 배포합니다.
